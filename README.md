# MoneyMates

Aplicación web de gastos compartidos. Permite organizar gastos por grupos y consultar el balance de cada grupo.

[Visitar la web](https://dnsue01.github.io/moneymate/)

## En el repositorio

El repositorio contiene la compilación web, un manifiesto y un service worker. Para revisar la publicación en local, sirve los archivos por HTTP bajo la ruta base `/moneymate/`.
